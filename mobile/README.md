# Mobile app

Expo SDK 57 client app (iOS and Android), routed with Expo Router from `src/app/`.

## Get started

```bash
npm install
npx expo start --ios      # or --android
```

## Configuration

| Variable | Purpose |
|---|---|
| `EXPO_PUBLIC_API_BASE_URL` | Base URL of the backend API. Inlined at bundle time. |

Resolution (`src/lib/config.ts`): `EXPO_PUBLIC_API_BASE_URL` if set, otherwise
`https://localhost:5001` in development builds only. A production build with the
variable unset throws at startup. Always use the HTTPS port in development: iOS drops
the `Authorization` header on an HTTP to HTTPS redirect. Trust the .NET dev cert in
the simulator with `scripts/trust-dev-cert.sh`.

## API client

`src/api/generated.ts` is generated by NSwag and must not be edited. Regenerate it
against a running backend with `npm run generate-api` (or `npm run generate-api:e2e`
for the compose harness). Use the shared client from `src/api/client.ts`.
