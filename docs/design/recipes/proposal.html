Drawer is now three tabs instead of one long form. Details = the wireframe's fields unchanged (image, Name, Servings, Description, Meal Type, Difficulty, Prep/Cook time, Dietary Preferences; Allergens shown read-only, derived from the ingredients). Ingredients = search foods, add a line, set grams; totals and per-serving values stay visible at the bottom. Preparation = an ordered list of steps: each step is a text box, reorderable by dragging, removable, "+ Add step" appends one. The small grey line under a step ("Oat flakes · Carrot, raw") is optional — it lists ingredients the step mentions, matched by name; drop it if it's noise. Needs a new backend field: an ordered list of step texts on the recipe.
